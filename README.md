# Students vs Teachers Trivia Scoreboard

A colorful classroom score tracker for a student versus teacher trivia contest. Use it on a laptop, tablet, or projector.

## Features

- Big bubble-letter scores for **Students** and **Teachers**
- **+** and **−** buttons to add or subtract one point
- A **15 second** countdown with **Start** and **Reset**
- A time’s-up flash and buzzer when the timer hits zero

## How to use

Open `index.html` in a browser, or start a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

1. Click **Start** to begin the 15 second timer.
2. Click **Reset** to stop the countdown and return it to 15.
3. Use the **+** and **−** buttons to keep score. Scores cannot go below zero.
